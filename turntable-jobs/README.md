# Turntable jobs

Esta carpeta es opcional.

1. En Illustrator abre **Pazos Turntable Local**.
2. Selecciona la ilustración y pulsa **Leer selección**.
3. Pulsa **Preparar GitHub Job**.
4. Se generan `source.svg` y `turntable-job.json`.
5. Solo si aceptas subir esa obra al repositorio, crea `turntable-jobs/<nombre>/` y añade ambos archivos.
6. En GitHub > Actions ejecuta **Turntable Render** indicando esa ruta.

La obra nunca se sube automáticamente desde Illustrator.
